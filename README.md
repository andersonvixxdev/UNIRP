# UNIRP

Repositório de estudos e exercícios das disciplinas do curso na **UNIRP** (Centro Universitário de Rio Preto).

## 📚 Disciplinas

### Linguagem de Programação I

Exercícios práticos de HTML e CSS desenvolvidos durante as aulas.

| Pasta                                                                  | Descrição                                                                                                         |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [`html_primeiraAula/`](<LINGUAGEM DE PROGRAMACAO I/html_primeiraAula>) | Primeira página HTML da disciplina — estrutura básica, imagem e vídeo de aula.                                    |
| [`html_principal/`](<LINGUAGEM DE PROGRAMACAO I/html_principal>)       | Exercício de estilização com CSS: uso de `class`, `id` e estilo aplicado ao `body`.                               |
| [`exercicio01/`](<LINGUAGEM DE PROGRAMACAO I/exercicio01>)             | Currículo em HTML/CSS (Anderson Martins — Consultor Protheus). Também disponível compactado em `exercicio01.zip`. |
| [`css/`](<LINGUAGEM DE PROGRAMACAO I/css>)                             | Estilos auxiliares utilizados nos exercícios.                                                                     |
| [`bootstrap/`](<LINGUAGEM DE PROGRAMACAO I/bootstrap>)                 | Biblioteca [Bootstrap](https://getbootstrap.com/) (CSS/JS) usada como referência/apoio nos exercícios.            |

## ▶️ Como visualizar

Não há build nem dependências — são páginas HTML estáticas. Basta abrir o arquivo `index.html` desejado diretamente no navegador, por exemplo:

```
LINGUAGEM DE PROGRAMACAO I/exercicio01/index.html
```

## 🗂 Estrutura

```
UNIRP/
└── LINGUAGEM DE PROGRAMACAO I/
    ├── bootstrap/           # Framework Bootstrap (vendored)
    ├── css/                 # Estilos auxiliares
    ├── exercicio01/         # Currículo em HTML/CSS
    ├── exercicio01.zip
    ├── html_primeiraAula/   # Primeira página da disciplina
    └── html_principal/      # Exercício de CSS (class/id)
```
